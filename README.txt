1) سوّ حساب على github.com وأنشئ Repository جديد (New repository).
2) ارفع كل محتويات هذا المجلد (بما فيها مجلد .github) عن طريق Add file > Upload files.
3) ادخل تبويب Actions، اختر Build APK، ثم Run workflow. انتظر 5-8 دقايق.
4) افتح التشغيلة الناجحة ونزّل waqti-apk من Artifacts، فك الضغط وثبّت app-debug.apk على جوالك.
5) أول مرة افتح التطبيق واسمح بالإشعارات والتنبيهات الدقيقة.
